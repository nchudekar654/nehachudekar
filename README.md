# Neha — Portfolio & Resume

A responsive, single-page portfolio built for GitHub Pages.

## Personalize before publishing

Search `index.html` for the uppercase prompts and replace them with your own details:

- `YOUR ROLE / AREA OF EXPERTISE`, `YOUR INTEREST OR SPECIALTY`, and `YOUR LOCATION`
- Timeline role, company, education, dates, and descriptions
- Project titles, descriptions, categories, links, skills, and tools
- `YOUR.EMAIL@example.com` and your LinkedIn profile URL
- The sample illustrations and project-card visuals can be replaced with screenshots or photography

The GitHub profile link is already set to `https://github.com/nchudekar654`.

## Publish with GitHub Pages

1. Commit these files to the `main` branch at the repository root.
2. Open **Settings → Pages** in this repository.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
4. After the deployment finishes, the portfolio will be available at **https://nchudekar654.github.io/**.

The site uses plain HTML, CSS, and JavaScript; no build step is required. Google Fonts are loaded remotely, with system fonts as fallbacks.
